分類値・Noul・検索語の初期値は空で、既存の結果に合わせた合成値を入れていない。実分類は保存済みJEV応答から適用する。`saved-responses.json` は空の未実行コレクションで、生成した順位を実LLM応答として扱わない。全質問は `smoke=false` で `--large` を使う。既存v1の権限・撤回・複数職歴等の回帰は別集合として維持する。
