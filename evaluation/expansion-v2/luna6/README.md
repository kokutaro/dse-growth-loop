# Luna6による再順位付けの実行準備

2026-10-03。Issue #14 の実JEV一次検索に、LLMの再順位付けを追加する。**本評価の有料実行は費用実測後のユーザー承認待ち**。既存の一次評価結果・正解ラベル・一次設定を変更しない。

## モデルと出力契約

既存Foundryに評価専用 `dse-luna6-eval` を追加することと、計測1件（最大4試行、上限$0.05）はユーザー承認済み。デプロイ作成は完了、`gpt-6-luna` / `2026-09-22` / `GlobalStandard` / capacity 1。本番の `dse-luna` は変更していない。

`response_format=json_schema`、`strict=true`。応答は `{"items":[{"candidateId":"...","reason":"...","evidenceIds":["..."]}]}`。全フィールド必須、追加フィールド禁止。JSON構文・スキーマ不一致のみ**初回＋パースリトライ3回＝最大4回**。同じ固定入力を再送し、各試行のusageを費用に加える。HTTPエラー、モデル不一致、拒否、出力打切り、架空ID、根拠にない引用は終了する。HTTP自動リトライは0回。

不適合候補は省略し、全候補不適合なら空配列を認める。理由は引用した根拠本文に含まれる連続した原文。候補ID・根拠IDの所属、重複・引用をローカルでも検証する。質問・原本を非信頼データとして扱い、正解ラベルをモデルへ送らない。

## 計測と比較の計画

[調整集合の計測入力](pilot-task.json)は正解を含まない1件。[本評価計画](plan.json)は、既に固定したEの確認24問を使用する。各質問で元順序1回・逆順序1回・元順序の独立再実行1回を比較する。72条件中、候補0件の1問×3条件は推論不要、**有料リクエストは通常69回、全件パース失敗時276試行**。独立再実行の `attempt` と内部パース再試行は別物。根拠本文は候補ごとUTF-8で1,000バイト、分類確率は送らない。プロンプト・モデル・候補hashを共通化し、入力順序への依存と同条件再実行の安定性を確認する。根拠量・確率有無などの追加比較は今回の69回に含めない。

既存 `RerankComparisons` の比較形式へ変換できる `items/entityId` を保存する。最終HitRate@5（正解あり20問中18問）、Precision・nDCG、正解なし4問の誤推薦、構造化精度、根拠ID整合、初回成功率・リトライ後成功率・失敗理由を評価する。一次検索で落ちた正解はLLMでも回復できない。今回のAPI時間はLLM単体であり、Cosmosを含む検索ウォームp95の合否には使わない。

[Microsoftの公表料金](https://azure.microsoft.com/en-us/blog/gpt-6-astra-sol-and-luna-for-production-agents-in-microsoft-foundry/)は100万トークンあたり通常入力$0.10、キャッシュ入力$0.01、出力$0.50。短コンテキストのGlobal Standardを使用する。計測usageの入力・キャッシュ・出力・推論内訳を保存し、キャッシュ入力は二重計上しない。推論トークンは出力の内数。費用は実測usage×公表単価による推計で、実請求照合ではない。

入力予約上限16,000トークン、出力上限2,000トークン。送信JSONのUTF-8バイト数＋フレーム余裕512が入力予約上限以下か確認する。usage未取得時は満額予約として保守計上する。1試行の予約額$0.0026、計測最大4回$0.0104、本評価最大276回$0.7176。この上限値は実測に基づく通常費用の見積もりと分けて報告する。計測1件は入力789・出力146トークン、キャッシュ0・推論0トークン、推計$0.0001519。通常69件が同程度の場合は$0.0104811。1件だけの実測であり質問ごとの差を代表する保証はない。

## 再送防止と現状

送信前に承認ID・入力hash・pending状態をfsync保存し、試行ごとのusageを永続化する。完了応答は再送しない。pendingや入力変更は手動レビューが必要。HTTP例外や認証情報をログに書かない。キーはgit無視の `.env` の `AZURE_OPENAI_API_KEY` を利用でき、未設定時はAzure CLIのEntraトークンを使う。アカウントキー取得・RBAC変更は行わない。

初回計測はusage未取得で失敗した。推論を再送しないモデル一覧のGET診断でも HTTP 401 / `PermissionDenied` を確認した。キー設定後の計測は成功し、**トークンと1件費用は取得済み、確認集合の品質改善値は未取得**。失敗計測の$0.0026は予約上限であり実測費用ではない。[証跡](../../../docs/validation-results/20261003-issue-14-luna6/pilot.json)を保持する。ユーザーのキー設定後、GETがHTTP 200になることを確認し、[計測を再開した](../../../docs/validation-results/20261003-issue-14-luna6/pilot-key.json)。前の失敗1回を含めた最大4回を守るため、再開時の残り上限は3試行に制限した。実際は1試行で成功、合計2試行。本評価は新たな費用承認まで実行しない。

検証は `python3 -m unittest discover -s tests/scripts -p test_llm_rerank_evaluation.py`。実LLM品質と混同しないネットワークなしの契約テスト。

[費用実測と承認用見積もり](../../../docs/validation-results/20261003-issue-14-luna6/cost-estimate.json)。本評価69件について実行上限$0.75の承認を求める。
