# 技能要素化とレビュー v1

大分類(domain)と具体技能は別契約である。引用/rawは原文のまま保存し、文字どおりの引用整合性と意味的支持、人の経験としての公開適格性を別々に扱う。

`scoped-assertion-v3` は、完了した主節の作業にかかる否定条件を解析用の複製上で扱う。条件内の未実施動作は経験にせず、希望・相談・伝聞・他者・チームだけの実績、引用改変を通さない。不明な構文は隔離する。これは日本語の一般的な構文解析や人手確認の代替ではない。

`skill-elements-v1` は raw を置き換えず、明示された共通動作に対する並列対象だけを最小単位へ分け、動作・対象・条件・実務/知識/参照/資格・主体・関与・原文位置を保持する。中点やスラッシュ、役割句、入れ子の述語を機械的に分割しない。原文にない主体や対象を補わない。同義語の概念IDは既存の承認済み別名対応だけを使い、モデルの正規化案は未承認のまま残す。同じ概念IDだけで技能一致にしない。

人物経験の検索語と知識資料の内容語を分離する。知識資料で保持した訓練手順は人物経験タグへ入れない。参照・資格も実務経験に変換しない。旧レコードは再評価時に現在の原文・種別から派生情報を再計算する。既存の検索投影はこのローカル変更だけでは再作成しないため、配信前に通常の再投影計画が必要。

今回の公開範囲は製品の根拠解析・候補化・辞書レビューと回帰検査です。旧自由記述評価の採点規則や正解原本を変更しません。新たな意味品質の保証には、方式固定後の独立した人手確認済みセットが必要です。過去の既知120件を未見評価とは扱いません。
