## 配備対象

以前の架空2資料を使う承認・辞書版・資料検索を、既存認証付き画面の `/skill-demo.html` から利用できるようにする。通常の技能ID検索も含む。共有辞書の初期版は0だったため、配備だけでは以前の候補を操作できない。共有資料を投入する代わりに、本人の現在権限を確認する専用メモリセッションを追加した。

セッションの業務レコード・辞書・監査は共有ストアへ書かず、1時間またはサーバー停止・再起動で失効する。同時最大8件。以前の資料、旧4案の履歴、個別化した6知識候補だけを用意する。実AI呼出しはサービス構成から除外し、提案APIも409で拒否する。既存のoperator権限を使用し、IAMの追加はない。
