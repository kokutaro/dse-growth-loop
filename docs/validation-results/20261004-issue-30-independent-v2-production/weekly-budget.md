# 週次予算への変更（2026-10-04）

人による追加承認に従い、AIと検証用インフラの合計上限を週2,000円、固定換算を1 USD＝162円に変更した。週は日本時間の月曜0時から翌月曜0時まで。承認証跡は[承認記録](../../../evaluation/issue-30/independent-v2/approved/weekly-budget-approval.json)に記載する。元のラベル・原文・検索設定・モデル・単価は変更しない。初回の独立評価結果を予算変更後の再試行で置き換えない。

## 台帳と移行

停止中に当週の全 `aiReservation` を読み、予約時の為替でUSDに戻して週次台帳へ引き継ぐ。成功分だけでなく、未確定・中断分の予約額も残す。完全なUTC日の件数と日次台帳が不一致なら初期化を拒否する。同じ承認での再初期化は既存台帳を返し、利用額をリセットしない。

週次台帳のUSD×162円と留保の合計で予約を制御する。API外のAIに200円、インフラに1,000円を予算内で留保し、実行時AIに残り800円を割り当てる。留保は実測請求額ではない。[過去費用の再換算](weekly-cost-reconciliation.json)には、別の検証で未確定となった推論も含める。二重計上を避け、アプリ内の過去評価は永続台帳から取り込む。

## 維持する制限

日次450万token、入力16,000・出力3,000token、同時実行1、試行1回、60秒timeoutを維持する。旧日次240call・200円の代わりに週次1,680call・合計2,000円を用いる。Issue30の実行単位362call、API累計4時間、Job累計2時間も維持する。週次台帳が存在しない週や為替が承認値と違う設定は送信前に停止する。新しい週は停止中の明示初期化が必要で、自動解除しない。

Azure Budgetは通知であり請求の強制停止機構ではない。台帳はアプリからの推論を制御するが、Azure全サービスの実請求を原子的に制御できない。インフラは稼働時間の上限と停止確認、予算内の留保で管理する。
