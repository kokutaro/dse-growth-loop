# 職務経歴書Excelの取込

Excelは[全テキスト取込とセル根拠](full-workbook-ingestion.md)へ一本化した。旧テンプレート互換は提供しない。

Google SheetsはXLSXへ書き出して既存の認可済みアップロードへ登録する。シート名・見出し・行列数・固定セルの位置を前提にしない。全シートの文字データ、結合範囲、表示/非表示、取得不能値と出典を保持し、AIが文脈から案件/案件外を構造化する。コードは形式・根拠・被覆・認可・版の整合性を検証する。

主担当/副担当や技術列だけの経験認定、旧技能列の機械的分割・正規化、旧テンプレートの専用レビュー表示は行わない。通常の出典プレビュー・経験/知識の確認候補を使い、人の承認境界を維持する。

原本・過去世代・監査・消費済み枠を削除/初期化しない。全取得情報のないExcelの再処理は理由付き保留にし、必要なら既存の明示見積・版付き再抽出を使う。本番再処理や自動承認はこの仕様変更に含まない。

`web/tests/fixtures/internal-resume.xlsx` と `WorkbookTextFixture` は、過去に作成した合成の多シートXLSX試験資材であり、本番に特定形式を選択させるものではない。固定形だけでなく行列移動、結合、説明・非表示・追加シート等を全テキストとして検証する。
