# 匿名の相談を起点にしたデザイン修正版

2026-10-06。`design/employee-workspace` の旧初案 `ac0a074` からの追加修正。main基点は `78f182a3`。初回レビュー時は未commit・未push。後続のユーザー承認に基づき、同じブランチへの通常pushで保全する。PR・mainへのmerge・Azure deployは対象外。

## 修正の判断

旧初案は人材検索を入口にし、元の「課題から始め、匿名で参加を選ぶ」体験を十分に反映していなかった。元デモ `sites-project://appgprj_6a5c8a04c60c819185076c334c9f45b7` のソース確認結果（`3eb40135a7d4d660c6fb92335ad19e383b9fb10c`）を親スレッドから受け取り、7段階の構成、青い主操作、白いステージ、匿名の表示名へ戻した。

ただし既存APIは認証・アクセス制御を持つ一方、参加者同士の匿名性を保証する設計ではない。名前だけを隠して既存APIへ接続すると、IDや根拠から本人を特定できるおそれが残る。このため、修正版は **API非接続の操作可能なデザインプレビュー** として実装した。既存業務画面は変更・削除していない。本番の匿名化を完了した変更ではない。

## 体験と同意

1. 課題投稿：不具合調査・設計開発の相談。投稿者Aとして匿名投稿。
2. AIマッチング・通知：架空のExpert候補、広い経験分野、理由、参考スコア。
3. 許可・拒否：候補者本人向けの通知。参加は本人が選ぶ。
4. セッション参加：ケース内の匿名名と参加範囲を確認。
5. チャットで共創：匿名で会話、事例の要点を参照、退出可能。
6. クローズ・評価：結果・要約・利用目的を確認。公開時は投稿者・協力者それぞれの確認をシミュレート。
7. 知識として蓄積：個人を特定しない解決の要約。実際の社内公開は行わない。

「実名は双方が同意するまで開示されません」を一貫して表示し、このプレビューでは実名を最後まで開示しない。参加、実名開示、事例公開、事業分析の同意を混同しない。氏名・部署・メール・社員ID・個人プロフィール・原会話/原文書リンクは含めない。別ケースへの識別子の引継ぎは実装していない。固定の表示名は架空の一件を繰り返し試すためのサンプルであり、ケースをまたぐ識別規則ではない。

元デモの投稿者だけの3チェックボックスを完成仕様とは扱わない。要約や利用目的を変えると両者の確認が取り消される操作例を追加した。参加者切替はデモ操作に限る。本番で他者に代わって承認できる機能ではない。非公開の検索・分析はこのデモでは扱わないが、本番の権限仕様を確定するものでもない。

## 実装済みと構想の境界

今回動くのは画面遷移、入力、辞退・参加・退出、ローカルの会話追加、評価、公開確認の状態遷移。すべて画面内メモリーで、再読込で消える。API呼出し・AI処理・通知送信・永続保存・公開・検索反映・事業分析はない。CSPの `connect-src 'none'` も設定した。非同期処理を模した待ち時間は設けていない。未投稿・未参加状態、公開確認不足のエラーを用意した。

既存の自然文検索・条件編集・検索結果・課題/会話/知識の業務実装は既存画面に残る。このプレビューの事例紹介・候補スコアは既存検索の評価結果ではない。既存検索を匿名な相談へどう接続するかはAPI投影と認可の設計が必要。匿名プロフィール、事業化提案、相互実名開示、全社員への匿名事例公開の一貫した保証は完成機能として示していない。

## API接続前に必要な変更

- 検索結果は候補名・固定ID・出典の文書名/位置/抜粋を含み得る（`web/src/main.tsx`、`src/Dse.Domain/Retrieval.cs`）。匿名用途に必要な返却項目をサーバー側で限定する必要がある。
- 人物APIと公開プロフィールの読み取り権限、人物IDからの逆引きを見直す必要がある（`RecordEndpoints.cs`、AccessPolicy）。画面のリンクを消すだけでは足りない。
- 課題・セッション・メッセージはowner/participantなどの固定識別子を持つ。参加依頼のアクセス制御と、参加者同士の匿名化は別の要件（`Conversations.cs`、`web/src/conversations.tsx`）。
- 知識化の評価者・同意者の表示と、公開物の投影も匿名の視点で確認が必要。非公開ドラフトを全社員が読めると確認したわけではない。
- ケース内エイリアスの発行、相互開示の同意状態、撤回、管理者例外、ケースをまたぐ識別ルールは仕様未確定。今回勝手に追加しない。

認証・認可・API契約の変更は今回していない。匿名性を満たすまでこのプレビューを実データへ接続しない。
